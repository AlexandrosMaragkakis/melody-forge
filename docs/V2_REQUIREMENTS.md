# Melody Forge V2 requirements traceability

This is the normative, mechanically auditable registry for the V2 expansion. A row is not complete merely because code exists: `done` requires the listed implementation, UI (when applicable), deterministic automated evidence, browser evidence, and accurate documentation. Planned paths may move during implementation, but the row must then be updated rather than removed.

Status vocabulary is exactly: `not started`, `in progress`, `done`, `blocked`.
